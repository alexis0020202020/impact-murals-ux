# Copy Constraints for Later Content Integration

These are working ranges, not rigid limits.

- Hero headline: 8–16 words
- Hero support: 14–28 words
- Context statement: 12–28 words
- Project statement: 12–35 words
- Project scope: 2–8 words
- Studio body: 35–80 words
- Final CTA heading: 6–14 words
- Final CTA body: 18–45 words

Copy should remain:
- concrete;
- human;
- commercially clear;
- free of mystical filler;
- free of inflated claims.
