# Visual Signature — The Impact Field

## Purpose
This document prevents the site from becoming a generic dark editorial agency template.

The visual signature must be specific enough that it could not be transferred unchanged to an architecture firm, a SaaS company, or another creative studio.

## Core metaphor
An impact changes a surface. It creates pressure, displacement, a trace, and a new alignment.

The interface should express this through controlled spatial behavior, not literal debris or explosion effects.

## Rules
1. Define a consistent impact origin in the hero.
2. Derive motion vectors, fracture lines, and reveal directions from that origin.
3. Let typography and media behave like layered surfaces.
4. Use misalignment only as a temporary state; the final state should feel precise and resolved.
5. Reuse the grammar selectively across the page so it becomes recognizable.

## Hero application
- The logo reacts first.
- Headline planes may enter with slight depth offsets.
- A fracture line or opening becomes the path into the first project media.
- The CTA remains stable and immediately usable.

## Project application
- Media is treated as a surface plate.
- Project metadata behaves like architectural notation.
- The reveal can move from site context to art to detail to production.
- Different ratios create pace and prevent repetitive blocks.

## Motion character
- Weighted, deliberate, and physical.
- Short impulses followed by stable rest.
- No constant floating.
- No elastic cartoon bounce.
- No decorative particle systems.

## Pass condition
The identity spine passes only if a viewer can describe a distinct relationship between the logo, the hero composition, the transition, and the project treatment.
